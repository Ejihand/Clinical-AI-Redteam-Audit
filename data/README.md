# Data Folder (Important)

## What’s in here
- `clinical_audit_seed_data.csv`: the original 21-row seed dataset.
- `large_audit_dataset.csv`: a 1,000-row synthetic dataset generated by sampling + jittering the seed.

## Warning / Usage Notes
- This repository’s `large_audit_dataset.csv` is **synthetic** (generated) and intended for **testing / auditing** only.
- Do **not** treat these cases as real clinical records.
- If you generate new outputs locally (e.g., audit results), keep them out of git unless you explicitly decide to publish them.
